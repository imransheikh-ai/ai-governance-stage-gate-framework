# AI Stage-Gate Review Checklist Template

Copy this file for every new AI project. Fill in each gate as the project reaches it. Do not check a box until the evidence for it actually exists — this is a real control, not a formality.

**Project name:**
**Sponsor:**
**Date started:**

---

## Gate 1 — Investment Prioritization
*Is this idea worth funding compared to other ideas?*

- [ ] One-page problem statement written (what problem, who it helps)
- [ ] Rough size of benefit estimated
- [ ] Rough size of effort/cost estimated
- [ ] Compared against other candidate ideas in the current portfolio
- [ ] Decision recorded: **Approved to proceed / Deferred / Rejected**

Reviewer: __________________ Date: __________

---

## Gate 2 — Business Case Approval
*Will the benefits really outweigh the cost and effort?*

- [ ] Detailed cost estimate (people, tools, cloud/infra spend)
- [ ] Detailed benefit estimate (time saved, revenue, risk reduced)
- [ ] Timeline with major milestones
- [ ] Named accountable owner for the business case
- [ ] Decision recorded: **Approved / Sent back for revision / Rejected**

Reviewer: __________________ Date: __________

---

## Gate 3 — Architecture & Data Readiness
*Do we have the right data and technical foundation?*

- [ ] Data sources identified and access confirmed
- [ ] Data quality checked (accuracy, completeness, freshness)
- [ ] Rights/permissions to use the data confirmed
- [ ] Technical architecture documented (models, platforms, integrations)
- [ ] Decision recorded: **Approved / Needs data work first / Rejected**

Reviewer: __________________ Date: __________

---

## Gate 4 — Security & Risk Review
*Could this leak data, get hacked, or behave unfairly?*

- [ ] Data privacy review completed
- [ ] Security/penetration considerations reviewed
- [ ] Bias/fairness check completed for the intended user population
- [ ] Human override/escalation path defined
- [ ] Decision recorded: **Approved / Approved with mitigations / Rejected**

Reviewer: __________________ Date: __________

---

## Gate 5 — Operational Acceptance
*Is there a support and monitoring plan for daily real use?*

- [ ] Support plan defined (who helps users when it breaks)
- [ ] Monitoring/alerting plan defined
- [ ] Rollback plan defined
- [ ] End users briefed/trained
- [ ] Decision recorded: **Approved for pilot / Not ready**

Reviewer: __________________ Date: __________

---

## Gate 6 — Scaling Decision
*Did the pilot prove itself enough to roll out further?*

- [ ] Pilot usage data collected
- [ ] Results compared against the original business case (Gate 2)
- [ ] Incidents/issues during pilot reviewed
- [ ] Decision recorded: **Scale fully / Scale partially / Extend pilot / Stop**

Reviewer: __________________ Date: __________
